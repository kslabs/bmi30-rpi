# Детекция сигнала + управление DC-adapt (host)

## Идея

- Для каждого канала (ADC0/ADC1) берём **максимальный уровень** корреляционного массива.
- В хост-коде он считается как максимум по **нормализованному per-sample product** (примерно $[-1..1]$), далее переводится в устойчивый диапазон **0..65535**.
- Порог **адаптируется**: если максимум больше порога → `+2`, если меньше → `-1`.
- Если максимум **больше чем в 2 раза** превышает порог **второй раз подряд**, считаем что **сигнал пойман**.

## Управление адаптацией DC на устройстве

Используется команда `CMD_SET_DC_ADAPT` (firmware-dependent).

```python
from usb_vendor.usb_stream import USBStream, CMD_SET_DC_ADAPT

stream = USBStream()

# При детекции сигнала — заморозить адаптацию на устройстве
stream.send_cmd(CMD_SET_DC_ADAPT, b'\x00')

# Сигнал пропал — возобновить адаптацию на устройстве
stream.send_cmd(CMD_SET_DC_ADAPT, b'\x01')
```

Примечание: если в прошивке/хосте код команды отличается, можно переопределить через переменную окружения:

- `BMI30_CMD_SET_DC_ADAPT=0x1B`

## PWM индикация (Raspberry Pi)

- Выход: **PWM0 на GPIO12** (BCM 12).
- Сценарий звука: ~150мс тон → ~50мс пауза → ~150мс второй тон.
- ADC0: базовый тон около **3000 Гц**, ADC1: около **2000 Гц**.
- Второй тон выбирается в диапазоне:
  - ADC0: 2000..4000 Гц
  - ADC1: 1000..3000 Гц
  в зависимости от найденного phase shift между even/odd.

В хосте используется best-effort backend:
- `pigpio` (предпочтительно)
- `RPi.GPIO` (fallback)

Отключить звук можно так:
- `BMI30_BEEP_ENABLE=0`
