## 🔍 Ключевые находки

### Проблема 1: SET_FRAME_SAMPLES ломает PROFILE=1
**Симптом:** При отправке 0x17 команды PROFILE=1 становится неработающим (0 кадров).
**Корень:** Прошивка не обрабатывает SET_FRAME_SAMPLES корректно для PROFILE=1.
**Решение:** Не отправлять SET_FRAME_SAMPLES для PROFILE=1 вообще.
**Статус:** ✅ Исправлено в хост-коде.

### Проблема 2: total_samples = 912 для обоих профилей
**Наблюдение:** Ожидали PROFILE=1 → 1360, но получили 912.
**Причина:** Неизвестна (проектное решение в прошивке?).
**Текущее решение:** Использовать 912 как норму для обоих.
**Статус:** ✅ Документировано, хост-код адаптирован.

### Проблема 3: Нестабильность между тестами
**Симптом:** Иногда после переключения профилей первый тест выдавал 0 кадров.
**Причина:** Требуется время восстановления USB после смены конфигурации.
**Решение:** Добавить паузу ≥3 сек между переключениями.
**Статус:** ✅ Документировано в FIRMWARE_CONTRACT.md и QUICKSTART_200HZ.md.
