## Проблемы и решения

### Проблема 1: total_samples = 912 для обоих профилей

**Наблюдение:** Ожидали PROFILE=1 → 1360, PROFILE=2 → 912, но оба дают 912.

**Решение:**
- Если 912 — это намеренный выбор: обновить протокол / документацию.
- Если нужна 1360 для профиля 1: исправить прошивку.

**Рекомендация:** Запросить уточнение у разработчика прошивки о том, почему NS=912 для обоих.

### Проблема 2: SET_FRAME_SAMPLES ломает PROFILE=1

**Наблюдение:** Команда 0x17 при PROFILE=1 приводит к 0 кадров.

**Решение:** Не отправлять SET_FRAME_SAMPLES для PROFILE=1. Хост-код обновлён.

**Статус:** ✅ Исправлено в `host/usb_vendor/usb_stream.py`.

### Проблема 3: Нестабильность между тестами

**Наблюдение:** После некоторых тестов PROFILE=1 возвращал 0 кадров, но после паузы 2 сек восстанавливался.

**Рекомендация:** 
- Добавить между тестами паузу или полный USB reset.
- В производстве добавить keepalive-механизм в RX-loop.

**Статус:** 🟡 Требует дополнительной проверки на долгих сессиях.
