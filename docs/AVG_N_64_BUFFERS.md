# Расширение буферизации до 64 буферов

## Обзор изменений

Реализована поддержка усреднения до **64 буферов** (вместо прежних до 32) с **шагом 8** для оптимального баланса между гибкостью и простотой выбора в GUI.

## Доступные значения avg_n

**Новый диапазон:** `8, 16, 24, 32, 40, 48, 56, 64`

**Предыдущий диапазон:** `4, 8, 12, 16, 20, 24, 28, 32`

### Настройка в GUI

В верхней панели интерфейса доступен выпадающий список для выбора количества усредняемых буферов. Выбранное значение автоматически сохраняется в конфигурационный файл и применяется при следующем запуске.

### Команда по USB

**Формат:** `CMD_SET_STREAM_MODE` (0x1A)

**Payload:**
- Байт 0: `mode` (2 = AVG_ROI)
- Байт 1: `avg_n` (1..64, рекомендуемые: 8/16/24/32/40/48/56/64)

**Пример:**
```python
from usb_vendor.usb_stream import USBStream, CMD_SET_STREAM_MODE

stream = USBStream()
# Установить режим AVG_ROI с усреднением 48 буферов
stream.send_cmd(CMD_SET_STREAM_MODE, bytes([0x02, 48]))
```

**Пример через CLI:**
```
0x1A 0x02 0x30  // mode=2 (AVG_ROI), avg_n=48
```

### Оценка задержки

**Формула:**
```
Delay (ms) = avg_n × (1000 / buf_rate_hz)
```

**Пример для buf_rate = 200 Гц:**
| avg_n | Задержка (мс) |
|-------|---------------|
| 8     | 40            |
| 16    | 80            |
| 24    | 120           |
| 32    | 160           |
| 40    | 200           |
| 48    | 240           |
| 56    | 280           |
| 64    | 320           |

## Проверка текущего значения

**Проверка через USB статус:**
   ```python
   from usb_vendor.usb_stream import USBStream, CMD_GET_STATUS
   
   stream = USBStream()
   # Отправить GET_STATUS и проверить текущее avg_n в ответе
   ```

## История изменений

**Предыдущее состояние:**
- Максимум: 32 буфера
- Шаг: 4 (4/8/12/16/20/24/28/32)
- Список в GUI: 8 значений

**Новое состояние:**

## Примечания

- Увеличение avg_n улучшает соотношение сигнал/шум, но увеличивает задержку отклика.
- Для большинства приложений рекомендуется диапазон 16-32.
- Значения 48-64 предназначены для работы с очень слабыми сигналами при допустимости большей задержки.
