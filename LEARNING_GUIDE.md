# Длительное обучение адаптивного детектора

## 📋 Описание

Система для автоматического обучения детектора меток на реальных данных.

**Цель:** Максимально быстро детектировать сигнал метки при минимальной вероятности ложного срабатывания.

**Принцип работы:**
1. Калибруется по шуму (без меток) - собирает статистику 
2. Автоматически оптимизирует количество буферов усреднения (8-64)
3. Адаптирует пороги детекции к изменениям среды
4. Сохраняет данные каждый час автоматически

## 🚀 Быстрый старт

### 1. Проверочный тест (30 минут)

Перед длительным запуском проверьте что всё работает:

```bash
python3 test_learning_30min.py
```

**Что происходит:**
- Калибровка 2 минуты (уберите метки!)
- Обучение 28 минут
- Статистика каждые 5 минут
- Данные в `./adaptive_data_test_30min/`

**Что должно быть:**
- Скорость ~180-200 кадр/сек
- Пороги стабилизируются через 5-10 минут
- Файлы сохраняются в директорию

### 2. Длительное обучение (2+ суток)

После успешного теста запускайте основное обучение:

```bash
python3 adaptive_learn_continuous.py
```

**Что происходит:**
- Начальная калибровка 5 минут
- Непрерывное обучение
- Статистика каждые 15 минут
- Автосохранение каждый час
- Лог в `adaptive_learning.log`

**Остановка:** `Ctrl+C` - корректно завершит и сохранит данные

## 📊 Что смотреть

### Калибровка шума
```
CH0: порог=2500, шум=800±150
CH1: порог=2800, шум=900±180
```
- **Порог** - уровень для детекции (автоматически)
- **Шум** - средний уровень без меток
- **±** - стандартное отклонение

### Буферы усреднения
```
Буферы: текущие=32, оптимальные=24
```
- Меньше = быстрее, но больше ложных
- Больше = медленнее, но точнее
- Система находит оптимум автоматически

### Адаптивные параметры
```
Sigma CH0: 3.50, CH1: 3.80
```
- Коэффициент чувствительности
- Больше = меньше ложных, но можем пропустить слабые метки
- Меньше = больше чувствительность, но больше ложных
- Система адаптирует автоматически

Для изменения параметров отредактируйте в `adaptive_learn_continuous.py`:

```python

calibration_duration = 300  # 5 минут

# Интервал вывода статистики
stats_interval = 900  # 15 минут

# Интервал принудительного сохранения

    data_dir='./adaptive_data_continuous'

```

## ❓ Частые вопросы

**Q: Сколько нужно времени для хорошей калибровки?**
A: Минимум 12-24 часа для стабильной статистики шума. Но можно начинать использовать уже через 1-2 часа.

**Q: Что делать если много ложных срабатываний?**
A: Система автоматически адаптируется. Если через 24 часа не помогло - увеличьте начальную sigma в коде.

**Q: Нужно ли вносить/убирать метки во время обучения?**
A: Нет! Первые 5 минут - без меток (калибровка). Потом можно оставить как есть.

**Q: Можно ли остановить и продолжить?**
A: Да! Ctrl+C корректно сохранит данные. При следующем запуске продолжит с сохраненного состояния.

**Q: Сколько места на диске нужно?**
A: ~1-5 MB на сутки работы.

## 🐛 Проблемы

### USB не подключается
```bash
# Проверьте устройство
lsusb | grep cafe

# Сброс вручную
sudo usbreset cafe:4001

# Права доступа (добавьте в /etc/udev/rules.d/)
SUBSYSTEM=="usb", ATTRS{idVendor}=="cafe", ATTRS{idProduct}=="4001", MODE="0666"
```

### Нет данных
- Проверьте что stream получает фреймы (test_simple_stream.py)
- Проверьте логи в adaptive_learning.log
- Убедитесь что USB не отключается

### Низкая скорость
- Нормально: 180-200 кадр/сек
- Если меньше 100 - проблемы с USB
- Проверьте загрузку CPU (должна быть <50%)
