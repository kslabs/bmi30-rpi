## Что должно измениться при исправлении

### До исправления (старое поведение):
- При запуске программа зависает на 10-15 сек ⏳
- Интерфейс полностью замирает
- Требуется ручной сброс устройства (нажать кнопку на плате)

### После исправления (новое поведение):
- При запуске интерфейс **немедленно** становится отзывчивым ✅
- Статус-бар показывает "Устройство подключено, ожидание данных…"
- Если устройство не отвечает:
  - Через 2 сек появляется сообщение: **"Поток пропал... сброс STM32"**
  - Автоматически выполняется SOFT_RESET
  - Затем DEEP_RESET
  - Затем аппаратный сброс GPIO17
  - Автоматическое переподключение без ручного вмешательства

## Где видеть логи

В консоли (или в файле при перенаправлении):
```bash
[RESET] SOFT_RESET sent via CDC
[RESET] Аппаратный сброс GPIO17…
[CONNECT] Creating USBStream, profile=2, fs=None
```

## Возможные проблемы и решения

### Если автосброс не срабатывает
1. Проверьте GPIO17 с помощью `gpioinfo`
2. Убедитесь, что `BMI30_AUTO_RESET_ON_STALL=1`
3. Увеличьте `BMI30_STALL_RESET_AFTER` если нужно больше времени на инициализацию

### Если запуск слишком медленный
1. Увеличьте `BMI30_HW_RESET_WAIT_S` для более дружественного сброса
2. Убедитесь, что никакие другие приложения не используют GPIO17
