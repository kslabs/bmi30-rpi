## 🔧 Настройка эвристик (опционально):

Если автоматическая разметка работает плохо, откройте `host/ml_auto_train.py`
и настройте пороги в функции `auto_label_capture`:

```python
amplitude_threshold = 2000.0      # порог амплитуды
correlation_threshold = 1000.0    # порог корреляции  
snr_threshold = 10.0              # порог SNR (dB)
product_threshold = 500000.0      # порог продукта
stability_threshold = 0.7         # порог стабильности
```
