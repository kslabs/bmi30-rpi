# Исправление работы частот - 19 января 2026

## Проблема
GUI показывал частоты, но команды на устройство не отправлялись корректно. Частоты были жестко привязаны к профилям (1=200Гц, 2=300Гц), что не позволяло использовать произвольные частоты.

## Решение

### 1. Убрана жесткая привязка частот к профилям
- Удалены все упоминания "1=200Гц / 2=300Гц"
- Частота теперь задается независимо от профиля через `desired_freq`

### 2. Исправлена отправка команды частоты на устройство

#### При старте стрима (строка ~5510):
```python
# Устанавливаем выбранную частоту
freq_to_set = getattr(self, 'desired_freq', 200)
if hasattr(self.stream, 'set_block_rate'):
    self.stream.set_block_rate(freq_to_set)
else:
    # Fallback: отправляем команду CMD_BLOCK_HZ (0x11) напрямую
    import struct
    self.stream.send_cmd(0x11, struct.pack('<H', freq_to_set))
```

#### При смене частоты (строка ~5923):
```python
# Явно задаём частоту блока
if hasattr(self.stream, 'set_block_rate'):
    self.stream.set_block_rate(self.desired_freq)
    print(f"[freq_change] Set block rate to {self.desired_freq} Hz via set_block_rate()")
else:
    # Fallback: отправляем команду CMD_BLOCK_HZ (0x11) напрямую
    import struct
    self.stream.send_cmd(0x11, struct.pack('<H', self.desired_freq))
    print(f"[freq_change] Set block rate to {self.desired_freq} Hz via CMD_BLOCK_HZ")
```

### 3. Добавлено логирование
Теперь в консоль выводятся сообщения при установке частоты:
- `[freq_change] Set block rate to XXX Hz via set_block_rate()`
- `[freq_change] Set block rate to XXX Hz via CMD_BLOCK_HZ`
- `[freq_change] Failed to set frequency: <error>`

## Команда для устройства

**CMD_BLOCK_HZ = 0x11** - устанавливает частоту блока в Гц
- Формат: 1 байт команды (0x11) + 2 байта частоты (little-endian uint16)
- Пример: `0x11 0xC8 0x00` = 200 Гц
