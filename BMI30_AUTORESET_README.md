# BMI30.200.py - Версия 2026-02-07 + AUTORESET

## Описание
Это модифицированная версия от 2026-02-07 со встроенным механизмом автоматического сброса STM32 при зависании USB потока.

## Ключевые изменения

### 1. Быстрый автосброс при зависании
- **Таймаут**: 2 секунды (вместо 15 секунд в более поздних версиях)
- **Cooldown**: 10 секунд между попытками сброса
- Автоматически определяет зависание потока по нескольким критериям:
  - Нет приема данных от устройства
  - Нет новых стереопар (кадров)

### 2. Механизм восстановления
При обнаружении зависания выполняется последовательность:
1. SOFT_RESET через CDC порт (если доступен)
2. DEEP_RESET через bulk endpoint (если доступен)
3. Аппаратный сброс через GPIO (если настроен)
4. Автоматическое переподключение с восстановлением всех параметров

### 3. Настройка через переменные окружения

```bash
# Включить/отключить автосброс (по умолчанию включен)
export BMI30_AUTO_RESET_ON_STALL=1

# Таймаут до сброса в секундах (по умолчанию 2)
export BMI30_STALL_RESET_AFTER=2

# Cooldown между попытками сброса (по умолчанию 10)
export BMI30_STALL_RESET_COOLDOWN=10

# GPIO для аппаратного сброса (по умолчанию 17)
export BMI30_HW_RESET_GPIO=17

# Длительность импульса сброса в мс (по умолчанию 100)
export BMI30_HW_RESET_PULSE_MS=100

# Время ожидания после сброса в сек (по умолчанию 3.0)
export BMI30_HW_RESET_WAIT_S=3.0
```

## Запуск

### Через меню переключения версий:
```bash
./switch_version.sh
# Выберите опцию: 2) 2026-02-07 + AUTORESET
```

### Через VSCode задачи:
`Ctrl+Shift+P` → "Tasks: Run Task" → "Переключить версию BMI30" → выберите опцию 2

### Напрямую:
```bash
./.usbvenv/bin/python host/BMI30.200.py.2026-02-07-autoreset
```

## Преимущества

✅ **Быстрое восстановление** - всего 2 секунды до сброса вместо 15  
✅ **Автоматическое восстановление** - не требует ручного вмешательства  
✅ **Восстановление параметров** - все настройки устройства применяются после сброса  
✅ **Защита от петель** - cooldown предотвращает бесконечные перезагрузки  

## Применение

Эта версия идеальна для:
- Отладки нестабильных прототипов
- Длительных тестов, где важна отказоустойчивость
- Ситуаций, когда устройство периодически зависает
- Автоматизированных систем без оператора
