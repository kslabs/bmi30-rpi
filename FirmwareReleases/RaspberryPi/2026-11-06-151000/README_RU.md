# Raspberry Pi 2026-11-06-151000

Пакет для **ручного обновления runtime BMI30 через обычный серверный updater**. Он подготовлен на основе проверенного runtime 123518 и опубликован в BMI30 Hub; Root подтвердил полный повторный download с сервера и проверку SHA256. На новом M02 обычный updater показал доступность обновления; download, extract и проверка distributable прошли без установки.

На S07 и новом M02 остаётся установленная версия **2026-11-06-123518**. Delivery **151000 на эти приборы не устанавливался**. Его проверка в этом выпуске — локальная проверка пакета и проверка серверной доставки; новый аппаратный запуск 151000 не заявляется.

Core `2026-11-06-111748`, Engine `2026-11-04-185916`, common/dual detector, GUI, USB stream и Portal побайтно сохранены. Помимо метаданных изменены только два адаптера: Bluetooth по умолчанию использует собственный `socket.gethostname()`; обязательный для Portal `bmi30_full_bootstrap.py` заменён явным runtime-only `start()` без фоновой полной миграции. Штатный switcher копирует весь `bundle/project`, поэтому адаптер доставляется рядом с активным Core и находится установленным Portal по этому пути.

Из пакета удалены полный native installer и cohort helpers. Конфигурация и сохранённый режим в исходном пакете — пустые JSON-объекты. Это не расширение allowlist полной миграции. Пакет не обновляет ОС, системную сеть, STM32 или USB/eMMC installer; существующие локальный switcher и зависимости ОС остаются необходимыми. Работа с физическим прибором требует отдельной проверки после установки.

Архив: `bmi30_backup_20261106_151000.tar.gz`, **3217523 B**, SHA256 `129555be6524ee69f036516d2d03de086a5ab71d6c74cfb9a5e5dfccc03f8ba8`. Маркер: `bmi30_latest.env`, SHA256 `dcfd92e794a88703598ff948b6a5036d9aacf33d138cbce8a2ed9ab9a6c1ddb3`.

Проверки: 173 уникальных regular members, все 158 bundle-файлов покрыты SHA256SUMS, повторная детерминированная сборка, штатные marker/extract_verified/verify_bundle/ensure_distributable, модель активации Portal sidecar и 7 локальных тестов PASS. Исходный build-report сохраняет историческое `published=false`; последующая фактическая публикация подтверждена Root и описана выше. Независимый peer report остаётся свидетельством source/local review, а не аппаратной установки.

В каталоге сохранены архив и marker, точные builder/test, author build-report и independent-review. `public-release-manifest.json` содержит SHA256 и размер каждого файла каталога, кроме самого manifest. Приватные device state, credentials, записи, SSH-ключи и полные USB-образы сюда не включены.
