# Управление частотой буферов в GUI

## ✅ Что добавлено

В GUI (BMI30.200.py) добавлен выпадающий список для управления частотой следования буферов в диапазоне **200-210 Гц**.

### Расположение

Контрол находится в верхней панели, справа от селектора количества усреднений (avg_n), перед кнопкой переподключения (↻).

### Использование

1. **Запустите GUI:**
   ```bash
   cd /home/techaid/Documents/host
   python BMI30.200.py
   ```

2. **Выберите частоту** из выпадающего списка:
   - Доступны значения: 200 Hz, 201 Hz, 202 Hz, ... 210 Hz
   - По умолчанию установлено: **200 Hz**

3. **Изменение частоты:**
   - При выборе нового значения команда автоматически отправляется на устройство
   - В статусной строке появится сообщение: "Частота буферов установлена: XXX Гц"
   - Если устройство не подключено, появится сообщение о том, что частота будет установлена при подключении

### Технические детали

**Команда USB:** `CMD_SET_BUF_RATE_FINE` (0x1C)  
**Формат:** `[0x1C, hz_low, hz_high]`

**Реализация:**
- `usb_vendor/usb_stream.py`: Метод `set_buf_rate_fine(hz: int)`
- `BMI30.200.py`: Обработчик `_on_freq_change(text: str)`

### Тестирование

Для проверки функциональности запустите тест:
```bash
cd /home/techaid/Documents
python test_freq_control.py
```

Тест проверяет:
- ✓ Установку частот 200, 203, 205, 207, 210 Гц
- ✓ Отклонение значений вне диапазона (199, 211 Гц)
- ✓ Корректность отправки команд на устройство

### Проверка через логи устройства

После изменения частоты в UART/CDC появятся логи:
```
[ADC][RATE] Fine-tune: 205 Hz (samples=600, Fs=123000 Hz, ARR=2235)
[CMD_IND] SET_BUF_RATE_FINE 205 Hz OK
```

### Применение

**Сценарий 1: Поиск оптимальной частоты**
1. Запустите GUI
2. Начните захват данных
3. Последовательно меняйте частоту от 200 до 210 Гц
4. Анализируйте качество сигнала на каждой частоте
5. Выберите частоту с наилучшими характеристиками

**Сценарий 2: Проверка переходных процессов**
1. Установите низкую частоту (200 Гц)
2. Запустите мониторинг DC offset
3. Резко переключите на высокую частоту (210 Гц)
4. Наблюдайте стабилизацию системы

**Сценарий 3: Диагностика синхронизации**
- При проблемах с синхронизацией попробуйте изменить частоту на ±1-2 Гц
- Некоторые частоты могут давать лучшую стабильность в зависимости от условий

### Ограничения

- Диапазон: **200-210 Гц** (расширение требует модификации прошивки)
- При переключении частоты возможен пропуск 1-2 буферов (TIM15 перезапускается)
- Для критичных приложений рекомендуется останавливать streaming перед изменением частоты
