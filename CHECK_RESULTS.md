# Проверка результатов калибровки шума

## ✅ Что было исправлено

### Проблема 1: MAX всегда ~65535
**Было:** Использовался `max(data)` для кросс-канальной обработки  
**Стало:** Используется `mean(data)` для стабильной метрики

### Проблема 2: Even/Odd diff = 0
**Было:** `abs(max(even) - max(odd))` → всегда 0, т.к. оба ~65535  
**Стало:** `mean(|even[i] - odd[i]|)` → правильная посемпловая разница

### Проблема 3: Переполнение uint16
**Было:** Вычитание uint16 давало переполнение  
**Стало:** Приведение к float перед операциями
