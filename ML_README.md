## 🎯 Обзор системы

### Что делает система?

✅ **Автоматическое определение меток** - распознает различные типы сигналов  
✅ **Фильтрация шумов** - уменьшает количество ложных срабатываний  
✅ **Самообучение** - модель улучшается на основе реальных данных  
✅ **Онлайн-адаптация** - обновляется в процессе работы  
✅ **Множество признаков** - анализирует временную и частотную области  

### Компоненты системы

1. **ml_marker_detector.py** - основной модуль ML-детекции
   - FeatureExtractor - извлечение признаков из сигналов
   - SimpleMLClassifier - классификатор с онлайн-обучением
   - MLMarkerDetector - высокоуровневый интерфейс

2. **ml_training_gui.py** - GUI для обучения модели
   - Просмотр захваченных данных
   - Разметка сигналов (метка/шум)
   - Обучение и тестирование модели
   - Статистика

3. **ml_auto_train.py** - автоматическое обучение
   - Автоматическая разметка на основе эвристик
   - Пакетное обучение модели
   - Статистика и валидация

## 🏗️ Архитектура

### Извлечение признаков (Features)

Система извлекает следующие признаки из сигналов:

#### Временная область
- `mean_amplitude` - средняя амплитуда
- `std_amplitude` - стандартное отклонение амплитуды
- `peak_amplitude` - пиковая амплитуда
- `snr` - отношение сигнал/шум (dB)

#### Частотная область (FFT)
- `dominant_freq` - доминирующая частота
- `spectral_centroid` - спектральный центроид
- `spectral_spread` - спектральное расширение

#### Корреляция
- `max_correlation` - максимальная корреляция между каналами
- `correlation_width` - ширина пика корреляции
- `correlation_symmetry` - симметрия корреляции

#### Продукт каналов
- `max_product` - максимальный продукт
- `product_std` - стандартное отклонение продукта

#### Временная стабильность
- `amplitude_variation` - вариация амплитуды во времени
- `correlation_stability` - стабильность корреляции

### Классификатор

**SimpleMLClassifier** - простой, но эффективный классификатор:

1. **Обучение**:
   - Вычисляет статистику (среднее, дисперсия) для каждого признака по каждому классу
   - Вычисляет веса признаков на основе их разделимости

2. **Предсказание**:
   - Для каждого признака вычисляет "похожесть" на каждый класс (Gaussian similarity)
   - Взвешивает по важности признака
   - Выбирает класс с максимальным взвешенным счетом

3. **Онлайн-обучение**:
   - Обновляет статистику с экспоненциальным сглаживанием
   - Адаптируется к новым данным без полного переобучения

### Поток данных

```
Устройство BMI30
    ↓
Фреймы данных (ADC0, ADC1, корреляция, продукт)
    ↓
Circular Buffer (последние N фреймов)
    ↓
FeatureExtractor: извлечение признаков
    ↓
SimpleMLClassifier: классификация
    ↓
Предсказание: (класс, уверенность)
    ↓
Детектор меток: принятие решения
    ↓
Действия: beep, freeze, capture
    ↓
[Опционально] Онлайн-обучение при получении обратной связи
```

### Использование scikit-learn

Для более продвинутых моделей (Random Forest, SVM, Neural Networks):

```python
# В ml_marker_detector.py
from sklearn.ensemble import RandomForestClassifier
from sklearn.preprocessing import StandardScaler

class AdvancedMLClassifier:
    def __init__(self):
        self.scaler = StandardScaler()
        self.model = RandomForestClassifier(n_estimators=100, random_state=42)
        self.feature_names = []
    
    def fit(self, X, y):
        # Преобразуем список словарей в numpy array
        self.feature_names = sorted(X[0].keys())
        X_array = np.array([[sample[f] for f in self.feature_names] for sample in X])
        
        # Нормализация
        X_scaled = self.scaler.fit_transform(X_array)
        
        # Обучение
        self.model.fit(X_scaled, y)
    
    def predict(self, features):
        X_array = np.array([[features[f] for f in self.feature_names]])
        X_scaled = self.scaler.transform(X_array)
        pred = self.model.predict(X_scaled)[0]
        proba = self.model.predict_proba(X_scaled)[0]
        confidence = np.max(proba)
        return pred, confidence
```
