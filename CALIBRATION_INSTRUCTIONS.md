**Данные**: `./noise_calibration_data/`

## Что делает система

### Собираемые параметры

**Индивидуальные каналы (CH0 и CH1):**
- **MAX** - максимальное значение (peak) в фрейме
- **MEAN** - среднее значение всего фрейма
- **RMS** - среднеквадратичное значение
- **P2P** - размах (peak-to-peak)

**Кросс-канальная обработка:**
- **SUM** = CH0 + CH1 (синхронный шум, далекие источники)
- **DIFF** = |CH0 - CH1| (несимметричный шум, близкие источники)
- **RATIO** = CH0 / CH1 (баланс каналов)
- **PHASE_SHIFT** - фазовый сдвиг между каналами (в семплах)
- **Correlation coefficient** - коэффициент корреляции Пирсона

**Метрики сигнала:**
- **Correlation** - взаимная корреляция массивов
- **Product** - произведение первых элементов

### Статистика для каждого параметра

Для ВСЕХ параметров вычисляется:
- `mean` - среднее значение
- `std` - стандартное отклонение
- `min` - минимум
- `max` - максимум
- `samples` - количество семплов

### Штатная остановка (Ctrl+C)
```bash

```

## Когда придете в понедельник

1. **Проверить что работает**:
   ```bash
   ps aux | grep calibrate_noise_2days
   tail -50 noise_calibration_continuous.log
   ```

2. **Остановить** (Ctrl+C или kill -2):
   ```bash
   kill -2 $(pgrep -f calibrate_noise_2days)
   ```

3. **Посмотреть результаты**:
   ```bash
   cat noise_calibration_data/noise_stats_FINAL.json
   ```

4. **Анализ**:
   - Если данные стабильные (малый std) - шум хорошо измерен
   - Если большой std - возможно были помехи или вариации
   - Correlation близкий к 1 - каналы работают синхронно
   - DIFF малый - симметричный шум
   - DIFF большой - есть несимметрия между каналами

## Что дальше

После анализа шума можно будет:
1. Установить адаптивные пороги: `threshold = mean + k*std`
2. Для каждого параметра свой порог
3. Учитывать кросс-канальные характеристики
4. Начать сбор данных с метками для обучения детектора
