# ТЗ: HTTPS Captive Portal для BMI30 (RU)

## Краткая инструкция

### Цель
Обеспечить открытие страницы портала Raspberry по HTTPS без предупреждений сертификата на любых устройствах.

### Что нужно от администратора
1. Выделить поддомен: portal.vinetabmi.cz.
2. Выпустить публичный TLS-сертификат для portal.vinetabmi.cz (рекомендуется Let's Encrypt, ACME DNS-01).
3. Настроить автопродление сертификата.
4. Организовать доставку сертификата и ключа на Raspberry после продления.
5. Настроить DNS так, чтобы в hotspot-сети portal.vinetabmi.cz резолвился в 10.42.0.1.
6. Открыть доступ к портам 80 и 443 на Raspberry в сети hotspot.

### Результат
- Пользователь открывает портал по HTTPS без ошибок сертификата.
- Captive flow запускается через HTTP probe ОС, после чего пользователь попадает на HTTPS-страницу.

## Подробная инструкция

### 1. Домен и сертификат
1. Зарезервировать FQDN: portal.vinetabmi.cz.
2. Выпустить сертификат от доверенного CA:
   - CN/SAN: portal.vinetabmi.cz
   - Формат артефактов: fullchain.pem + privkey.pem
3. Настроить автообновление сертификата (renewal) без ручных действий.
4. Настроить post-renew hook:
   - передать новые fullchain.pem и privkey.pem на Raspberry;
   - перезапустить HTTPS-сервис (Nginx/Caddy/другой фронт).

### 2. DNS
1. Публичная зона:
   - создать запись для portal.vinetabmi.cz по политике компании.
2. Локальная зона hotspot (dnsmasq на Raspberry):
   - принудительно резолвить portal.vinetabmi.cz в 10.42.0.1.
3. При необходимости настроить CAA-записи для выбранного CA.

### 3. Сеть и доступ
1. Разрешить клиентам hotspot доступ к:
   - TCP 80 (captive detection/probe);
   - TCP 443 (основная HTTPS-страница).
2. Убедиться, что firewall/NAT не блокирует локальные DNS-ответы и HTTP/HTTPS на Raspberry.

### 4. Поведение портала
1. Для probe-запросов ОС (Android/iOS/Windows/Linux) обработка остается на HTTP (порт 80).
2. После детекта captive portal пользователь перенаправляется на HTTPS-домен:
   - https://portal.vinetabmi.cz/login
3. На этапе внедрения не включать HSTS до подтверждения стабильности.

### 5. Передаваемые материалы от администратора
1. fullchain.pem
2. privkey.pem
3. (опционально) отдельный CA bundle
4. параметры DNS/API (если renewal через DNS-01)
5. контакты ответственного за DNS/PKI

### 6. Критерии приемки
1. На любом клиентском устройстве при открытии https://portal.vinetabmi.cz сертификат валиден.
2. В hotspot-сети домен portal.vinetabmi.cz резолвится в 10.42.0.1.
3. После перезагрузки Raspberry HTTPS продолжает работать.
4. Автопродление сертификата проверено (dry-run или тестовый cycle).
5. Пользователь может получить страницу портала без ручной установки сертификатов на телефон/ПК.

### 7. Ограничение
100% гарантия автопопапа captive окна на всех прошивках невозможна (логика ОС отличается),
но при корректной HTTP probe обработке и валидном HTTPS-домене портал открывается безопасно и предсказуемо.
