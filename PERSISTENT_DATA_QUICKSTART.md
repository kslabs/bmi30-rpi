# Быстрый старт: Персистентное хранилище данных

## Что изменилось

Адаптивный детектор теперь:
✅ Автоматически сохраняет данные каждый час
✅ Восстанавливает данные после перезагрузки
✅ Хранит все данные в отдельной папке `./adaptive_data/`
✅ Использует все 4 ядра процессора для ускорения
✅ Имеет кнопки управления данными в GUI

## Использование

### 1. Первый запуск

```python
from adaptive_realtime_detector import AdaptiveRealtimeDetector

# Создание детектора
detector = AdaptiveRealtimeDetector(
    min_buffers=8,           # минимум буферов для усреднения
    max_buffers=64,          # максимум буферов для усреднения
    data_dir='./adaptive_data',      # папка для данных
    auto_save_interval=3600,         # сохранять каждый час (3600 сек)
    use_multiprocessing=True,        # использовать 4 ядра
    num_workers=4                    # количество процессов
)
```

Вывод при первом запуске:
```
[ADAPTIVE] Нет сохраненных данных, начинаем с нуля
[MP] Инициализировано 4 рабочих процессов
[ADAPTIVE] Автосохранение каждые 3600 сек
```

### 2. Повторный запуск (после перезагрузки)

```python
# Тот же код - данные загрузятся автоматически
detector = AdaptiveRealtimeDetector()
```

Вывод при повторном запуске:
```
[ADAPTIVE] Найдены данные возрастом 3.5 часов
[ADAPTIVE] Данные успешно восстановлены
[STORE] Загрузка данных от 2026-01-15T12:30:45
[STORE] Данные успешно загружены
[MP] Инициализировано 4 рабочих процессов
[ADAPTIVE] Автосохранение каждые 3600 сек
```

### 3. Работа с данными

```python
# Обработка фреймов (как обычно)
for i in range(10000):
    detected_ch0, detected_ch1, conf0, conf1 = detector.process_frame(
        level_ch0, level_ch1, correlation, product
    )
    # ... ваш код ...

# Данные сохраняются автоматически каждый час

# Ручное сохранение (если нужно)
detector.save_now()  # сохранить прямо сейчас

# Сброс всех данных (если условия изменились)
detector.reset_all_data()  # удалить все данные + создать бэкап

# Проверка возраста данных
age = detector.data_store.get_data_age()
if age:
    print(f"Данные возрастом {age.total_seconds() / 3600:.1f} часов")

# Остановка с финальным сохранением
detector.stop()
```

## GUI панель

Новая секция "💾 Управление накопленными данными":

- **Индикатор возраста**: "Данные: 3.5 ч назад"
- **Кнопка "💾 Сохранить сейчас"**: Немедленное сохранение
- **Кнопка "🔄 Сбросить данные"**: Удаление данных + создание бэкапа

### Интеграция в BMI30.200.py

```python
from adaptive_realtime_detector import AdaptiveRealtimeDetector
from adaptive_detector_gui import AdaptiveDetectorPanel

# При инициализации
self.adaptive_detector = AdaptiveRealtimeDetector()
self.adaptive_panel = AdaptiveDetectorPanel(self.adaptive_detector)
self.main_layout.addWidget(self.adaptive_panel)

# При закрытии
def closeEvent(self, event):
    self.adaptive_detector.stop()  # Финальное сохранение
    event.accept()
```

## Структура папки данных

```
./adaptive_data/
├── noise_profile.json         # Профили шума CH0, CH1
├── buffer_calibration.json    # Оптимальное количество буферов

```

## Частые вопросы

### Как изменить интервал автосохранения?

```python
# Сохранять каждые 30 минут
detector = AdaptiveRealtimeDetector(auto_save_interval=1800)

# Сохранять каждые 2 часа
detector = AdaptiveRealtimeDetector(auto_save_interval=7200)
```

### Как отключить мультипроцессинг?

```python
# Для отладки или на слабом железе
detector = AdaptiveRealtimeDetector(use_multiprocessing=False)
```

### Что делать если условия работы изменились?

1. Нажмите "🔄 Сбросить данные" в GUI
2. Или вызовите `detector.reset_all_data()` в коде
3. Система создаст бэкап и начнет калибровку заново

### Где хранятся бэкапы?

В папке с суффиксом `_backup_` и меткой времени:
```
./adaptive_data_backup_20260115_123045/
./adaptive_data_backup_20260115_180530/
```
