Черновик алгоритма детектирования для метки «Б»

Цель: обеспечить максимально быструю реакцию (минимальная задержка), все расчёты должны быть простыми и работать на одном кадре.

Принцип: используем ТОЛЬКО средние значения (не медианы), чтобы избежать противоречий и лишних ветвлений. Медианы можно добавить позже как альтернативный режим.

1) Для каждого ADC выполняем посемпловое перемножение чётного и нечётного массивов со сдвигом на 1 семпл и ищем максимум полученного массива. Диапазон сдвига оставляем текущий (вопрос диапазона для нечётной фазы — позже).

2) Если амплитуда максимума достигла потолка шкалы, фиксируем детектирование метки сразу.

3) Иначе берём окно из 5 семплов вокруг максимума (2 слева + максимум + 2 справа) и считаем сумму.

4) Вычисляем среднее этого окна: $mean_max = sum_5 / 5$.

5) Проверяем значение амплитуды в точке $idx_max - 21$: превышает ли оно $0.5 · mean_max$?

6) Проверяем значение амплитуды в точке $idx_max + 21$: превышает ли оно $0.5 · mean_max$?

7) Для каждой стороны, где условие выполняется, считаем своё окно 5 семплов вокруг соответствующей точки (±21) и получаем $mean_left$ и/или $mean_right$. Если условие не выполнено — эту сторону не учитываем.

8) Обычно есть два «горба» (левый и правый), но их высоты могут отличаться.

9) Таким образом получаем средние значения по 5 семплам для обоих экстремумов и их центральные индексы, разнесённые на 21 семпл.

10) Определяем фон: берём все семплы вне зоны горбов — левее $(idx_min_hump - 21)$ и правее $(idx_max_hump + 21)$, но только там, где есть валидные пары чёт/нечёт.

11) Считаем среднее значение «сигнал‑метка» как среднее по доступным $mean_left/mean_right$ (или одному из них), а «фон» — как среднее по зоне без метки. Находим отношение $ratio = mean_signal / mean_noise$.

12) Сравниваем $ratio$ с коэффициентом срабатывания для соответствующего ADC из GUI. Если превышает — детектируем метку, иначе нет. Для ADC1 и ADC2 — отдельно.

Уточнения (без доп. задержек, всё в одном кадре):

13) Локальная нормализация: дополнительно считаем «локальный фон» в коротком окне вокруг $idx_max$ (например, 9–15 семплов, исключая 5-семпловое окно максимума) и используем его при расчёте $ratio$ вместо глобального фона, если локальный фон доступен.

14) Контроль ширины горба: считаем количество соседних семплов, где амплитуда $> 0.5 · mean_max$. Если ширина слишком мала или слишком велика — не учитываем соответствующую сторону при пункте 7.

15) Все расчёты выполняются в рамках одного кадра без накопления по времени.
