### Что было изменено

1. **GUI ComboBox** (строка ~447)
   - Изменен список частот с диапазона 200-210 Гц на конкретные значения
   - Частоты сохраняются и загружаются из конфигурации

2. **Функции конфигурации** (строки ~268-289)
   - `save_config()` - теперь сохраняет также desired_freq
   - `load_freq()` - новая функция для загрузки частоты из конфига

3. **Обработчик смены частоты** `_on_freq_change()` (строка ~5860)
   - Теперь парсит частоту из текста ComboBox
   - Использует `desired_freq` вместо жесткой привязки к profile
   - Сохраняет выбранную частоту в конфигурацию

4. **Инициализация** (строка ~365)
   - Добавлено `self.desired_freq` - текущая выбранная частота
   - Загружается из конфига при старте

5. **Reader thread** (строка ~4125)
   - Использует `self.desired_freq` для установки `self.freq_hz`

## Тестирование

Запустите тест:
```bash
python test_freq_list.py
```

Запустите GUI:
```bash
python host/BMI30.200.py
```

В GUI теперь доступен выбор из 9 частот. Выбранная частота сохраняется между запусками.
